## Chakka Attack

An endless, score-based arcade game. You are a spinning rock: dodge the spaceships' lasers, throw rocks back (as many as you like), and beat the boss that shows up at score 500 to unlock Boss Rush.

Built with Godot 4.5. Plays in the browser and on Android.

### Based on

Chakka Attack is a modified version of **Asteroid's Revenge** by MLM Games
(https://github.com/mlm-games/asteroids-revenge), used under its open-source licence (see `LICENSE`).
Changes: Hard Mode removed, boss at score 500, slightly easier, unlimited rock throws,
Help moved into Settings, English only, new menu look, custom rock picture.

### Build

Open the **Actions** tab, choose **Build Chakka Attack**, press **Run workflow**.
When it finishes, the APK and the web version are under **Artifacts** on that run.
To publish the web version, set Settings -> Pages -> Source to "GitHub Actions".
